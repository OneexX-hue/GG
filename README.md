# 🏆 Квест Платформа — Инструкция по запуску

## Способ 1: Docker (рекомендуется, самый простой)

### Что нужно установить
- [Docker Desktop](https://www.docker.com/products/docker-desktop/) (Windows / macOS / Linux)

### Запуск
```bash
# 1. Распакуйте архив в любую папку
# 2. Откройте терминал в этой папке
# 3. Запустите одну команду:
docker compose up --build
```

Подождите 1–2 минуты пока соберётся. Затем откройте браузер:

| Адрес | Что открывается |
|---|---|
| http://localhost | Страница игроков |
| http://localhost/admin | Панель администратора |

**Пароль администратора:** `admin123`

### Остановка
```bash
docker compose down
```

### База данных сохраняется автоматически
Данные хранятся в Docker volume `quest_data`. При повторном `docker compose up` все задания и игроки останутся.

## Способ 2: Запуск вручную (Node.js + pnpm)

### Что нужно установить
- [Node.js 22+](https://nodejs.org/) (обязательно версия 22 или новее — используется встроенный SQLite)
- pnpm: `npm install -g pnpm@10`

### Первый запуск
```bash
# В папке проекта:
pnpm install
```

### Запуск (два терминала)

**Терминал 1 — API сервер:**
```bash
cd artifacts/api-server
pnpm dev
# API доступно на http://localhost:8080
```

**Терминал 2 — Фронтенд:**
```bash
cd artifacts/quest
pnpm dev
# Сайт доступен на http://localhost:21234
```

> ⚠️ При ручном запуске фронтенд и API работают на разных портах.
> Откройте http://localhost:21234 для игроков и http://localhost:21234/admin для администратора.

## Игровой процесс

### Для игроков
1. Открыть http://localhost на телефоне (через Wi-Fi в одной сети)
2. Ввести имя и команду → нажать «Участвовать»
3. Ждать старта (задания появятся автоматически)
4. Вводить коды с точек маршрута

### Если игрок потерял сессию
На странице регистрации нажать **«Восстановить сессию»** → ввести то же имя и команду.

### Для администратора
1. Открыть http://localhost/admin
2. Пароль: `admin123`
3. Задать длительность в минутах (0 = без лимита)
4. Нажать **Старт** — задания сразу появятся у всех игроков
5. После игры нажать **Стоп** — появится подиум с победителями

## Как открыть для телефонов в локальной сети

При запуске через Docker сайт доступен на `http://<IP-вашего-компьютера>` для всех устройств в той же Wi-Fi сети.

Узнать IP:
- **Windows:** `ipconfig` → IPv4 Address
- **macOS/Linux:** `ifconfig` или `ip addr`

Например: `http://192.168.1.100`

## Часто задаваемые вопросы

**Q: Задания пропали после перезапуска**  
A: При Docker они сохраняются автоматически. При ручном запуске — файл `artifacts/api-server/data/quest.db`.

**Q: Хочу сменить пароль администратора**  
A: Пароль теперь проверяется и на сервере, поэтому меняйте его в двух местах на одно и то же значение:
1. `artifacts/quest/src/pages/Admin.tsx` — строка `if (password === "admin123")`.
2. Переменная окружения `ADMIN_PASSWORD` для API-сервера (в `docker-compose.yml` при запуске через Docker, либо `ADMIN_PASSWORD=... pnpm dev` при ручном запуске). Если её не задать, по умолчанию используется `admin123`.

**Q: Как сбросить игроков перед новой игрой**  
A: Панель администратора → кнопка «Сбросить игроков».
